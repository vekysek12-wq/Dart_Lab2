ToDo - консольное приложение на Dart
Простое консольное приложение для управления списком задач. Позволяет добавлять, просматривать, отмечать выполненными и удалять задачи через командную строку.

Запуск
Клонировать репозиторий:
git clone <url>

Перейти в папку:

Установить зависимости:

Запустить:
dart run

Ответы на вопросы
В чём разница между полем класса и обычной переменной в функции?
Поле класса принадлежит объекту (или классу, если static) и живёт столько же, сколько сам объект. Оно доступно во всех методах этого класса и сохраняет значение между вызовами. Обычная переменная внутри функции создаётся при входе в функцию и уничтожается при выходе; снаружи она не видна.

Что такое конструктор и зачем он нужен?
Конструктор — это специальный метод, который вызывается при создании объекта через ClassName(...). Он нужен, чтобы задать начальные значения полей и выполнить нужную настройку до того, как объект начнёт использоваться.

Зачем нужен @override перед toString()? Что будет, если его убрать?
@override — аннотация, которая говорит компилятору: «этот метод переопределяет метод родителя». Она нужна для проверки: если сигнатура не совпадает с родительской, компилятор сообщит об ошибке. Если её убрать, код всё равно скомпилируется и будет работать так же — toString() переопределится, потому что у Object уже есть этот метод. Но вы потеряете подсказки и защиту от опечаток (например, toStrng()).

Чем static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?
Обычное поле принадлежит каждому объекту отдельно: у 10 объектов — 10 копий поля. static-поле принадлежит самому классу, а не объектам: в программе существует ровно одна копия этого поля, общая для всех экземпляров. Обращение к нему — через имя класса: Todo._counter, а не через todo._counter.

Что означает нижнее подчёркивание в _counter?
Это признак приватности в Dart. Идентификатор, начинающийся с _, виден только внутри той библиотеки (файла), где он объявлен. Снаружи файла обратиться к _counter нельзя — компилятор выдаст ошибку. Это механизм инкапсуляции на уровне библиотеки.
